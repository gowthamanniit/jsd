type casting:
---------------
	convert one datatype to another datatype.
2 types:
	datatype casting
		- implicit (auto conversion) ex: higher bits = lower bits
		- explicit (user manual conversion) ex: lowerbit = higer bits
							
	object casting
		- upcasting	base = derive
		- downcasting   derive = base
