control statement:
===================
def: condition based execution

condition: a>34
	   mark>=50
	   m1>34 && m2>34 && m3>34
	   !(m>=35)
	   name.equals("admin") && pwd.equals("password@123")
1) simple if
	
	syntax:
	if (condition)
	{
	  statement;
	}

	ex:
	if(mark>34)
	{
	System.out.println("pass");
	}

2) if else statement

	syntax:
	if(condition)
	{
	 true statement;
	}
	else
	{
	false statement;
	}
	ex:
	if(mark>34)
	{
	System.out.println("pass");	
	}
	else
	{
	System.out.println("fail");
	}
